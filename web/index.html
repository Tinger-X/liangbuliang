进阶使用

授予 WRITE_SECURE_SETTINGS 权限（推荐）

在 Android 12 及以上，0.1%~1% 的超低亮度借助系统原生「Extra Dim」实现，需要手动授予一项系统保护权限。

  1. 1

    开启 USB 调试

    在设备的「开发者选项」中开启 USB 调试，并用数据线连接电脑。

  2. 2

    执行授权命令

    在电脑终端执行下方命令，即可授予权限。

  3. 3

    重启应用

    回到亮不亮，将亮度调至 1% 以下，即可体验平滑无跳变的超低亮度。

授权命令 
adb shell pm grant kg.edu.tin.liangbuliang android.permission.WRITE_SECURE_SETTINGS

也可通过 Shizuku 等工具在设备上直接授予该权限，无需电脑。

✅ 已授予权限

应用使用系统原生「Extra Dim」平滑调节 0.1%~1% 超低亮度，变化连续无跳变；即使后台进程被清理，1% 以下的亮度仍会保留。

⚠️ 未授予权限

应用退化为「屏幕遮罩」方案实现超低亮度；后台被清理时遮罩失效，1% 以下的亮度会回弹到 1%。

撤销权限

adb shell pm revoke kg.edu.tin.liangbuliang android.permission.WRITE_SECURE_SETTINGS
隐私说明

你的数据，只属于你

亮不亮申请的所有权限均服务于「调节屏幕」这一单一目的，且数据只在本地。

权限 / 数据 用途
WRITE_SETTINGS调节系统屏幕亮度与熄屏时长
WRITE_SECURE_SETTINGS在 Android 12+ 通过「Extra Dim」实现 0.1%~1% 超低亮度平滑调节
FOREGROUND_SERVICE后台持续维护用户设置
POST_NOTIFICATIONS前台服务通知
WAKE_LOCK保持屏幕常亮（仅当用户主动选择时）

所有设置数据仅存储在设备本地，不上传至任何服务器，无需注册、无需联网、无任何分析或广告追踪。

常见问题

你可能想知道

亮不亮收费吗？

完全免费、开源、无广告。你可以自由下载使用，也可以前往 GitHub 查看源码。

为什么低于 1% 需要额外授权？

Android 12+ 的 0.1%~1% 亮度依赖系统原生「Extra Dim」功能，该功能受系统保护，需通过 ADB 或 Shizuku 授予 WRITE_SECURE_SETTINGS 权限。

退出应用后设置会失效吗？

不会。启用后应用通过前台服务在后台持续维持设置，切换或退出应用都不会丢失；主动关闭功能时会自动还原原始设置。

数据会被上传吗？

不会。所有设置仅保存在设备本地，应用无需任何网络权限即可正常使用。
